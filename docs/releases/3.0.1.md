# OpenCore Helper 3.0.1 · CustomTkinter

## Português

Nova interface Windows em CustomTkinter, reunindo Auxiliary Tools, análise de EFI, OHV, downloads, recuperação e relatórios

- Editor de config.plist com todos os tipos, seções, busca, histórico, reordenação de arrays e proteção contra alterações externas
- Backup automático no salvamento, backup de EFI com manifesto SHA-256 e restauração em pasta nova
- Inclusão de ACPI, kexts e drivers sem apagar entradas existentes
- Edição de SMBIOS e geração por macserial oficial configurado pelo usuário
- Inspeção estrutural e execução do ocvalidate correspondente à versão do OpenCore
- Consultas CIM de hardware, com pendências de compatibilidade explícitas
- Downloads de releases oficiais, com digest quando disponível
- macrecovery do OpenCorePkg incluído, verificação de chunklist, cancelamento e conversão opcional DMG → VMDK com QEMU
- Português e inglês, idioma de interface do Windows e temas claro/escuro/sistema
- Build de EXE independente, pacote portátil e instalador NSIS x64, sem fontes Python expostas na distribuição

O editor integrado é independente. O OCAT original de ic005k continua sendo um aplicativo separado em Qt e pode ser aberto pelo Helper

A publicação deste lançamento depende dos testes automatizados e do build Windows. O workflow verifica widgets, pacote, instalação, atualização e desinstalação. Isso não valida o boot do macOS ou a compatibilidade de um computador específico

## English

New Windows CustomTkinter interface combining a typed plist editor, EFI inspection and verified backups, preliminary OHV findings, official release downloads, SMBIOS tooling, Apple recovery downloads and local reports

The self-contained x64 package includes Python; the setup installs under Program Files and preserves per-user preferences on update/uninstall. The integrated editor is independent of the original Qt-based OCAT, which can be launched separately

Use the ocvalidate matching your OpenCore release and review configuration for your hardware. These checks do not guarantee a bootable EFI. Packages are not digitally signed
