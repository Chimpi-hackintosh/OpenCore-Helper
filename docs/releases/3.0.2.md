# OpenCore Helper 3.0.2 · Recovery status correction

## Português

Atualização de manutenção para Windows x64, incluindo a correção já testada na branch principal

- O download de macOS Recovery deixa de apresentar o `BaseSystem.chunklist` como verificado criptograficamente, pois essa verificação **ainda não é implementada** na interface do Helper
- Mantidas a conferência da presença dos arquivos e a geração do SHA-256 **local** do `BaseSystem.dmg`, que não equivalem à autenticação do arquivo remoto
- Adicionado teste de regressão para impedir que o aplicativo anuncie uma verificação de chunklist que não ocorreu
- Versão do aplicativo, instalador NSIS, metadados do EXE, ajuda e documentação atualizados para 3.0.2

O pacote Windows inclui instalador EXE, ZIP portátil e SHA256SUMS, publicados somente após os testes e o build Windows serem aprovados no GitHub Actions

**Importante:** Esta atualização não implementa uma verificação criptográfica de chunklist e não garante a inicialização do macOS. Os executáveis não são assinados digitalmente

## English

Maintenance update for Windows x64 correcting how macOS Recovery download verification is reported

- The Helper no longer claims the `BaseSystem.chunklist` was cryptographically verified when it was not
- Local DMG SHA-256 and file-presence checks remain available, but do not authenticate the remote recovery
- Adds regression coverage for the verification-status report
- Updates the app, installer, executable metadata, help text and documentation to version 3.0.2

Release assets (EXE installer, portable ZIP, checksums) are uploaded only when the Windows build and tests succeed. Binaries are not code signed. This update does not guarantee a bootable EFI
